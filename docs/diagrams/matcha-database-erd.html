Data Model · Physical Schema

MatchA Database Schema (ERD)

Entity-Relationship Data Architecture: Normalized E-Commerce relational model supporting Personal Color seasonal tags, garment variants, order items, and referential constraints.

Inventory Architecture

Products & Color Variants

1-to-N normalized decomposition between high-level garments and specific SKU colorways. Supports live hex codes, seasonal tags (Spring/Autumn Warm, Summer/Winter Cool), and stock counts.

Referential Integrity

Orders & Line Items

Enforces strict relational constraints. Line items carry a cascade delete from their parent order while maintaining restrict constraints against deleted master catalog rows.

Customer Security

Membership & VIP State

The users table holds hashed credentials, system roles (Member vs Admin), and persistent customer Personal Color diagnosis for personalized catalog recommendations.
